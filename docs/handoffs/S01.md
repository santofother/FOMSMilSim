# S01 — Foundation (sim/game split, battle scene, tests)

## What exists now
- `src/Sim/FOMS.Sim.csproj` (net8.0, no Godot). Root csproj references it and excludes `src/Sim/**`, `tests/**`.
- M0 sim ported to `src/Sim/Core/` (`Battle`, `SoldierStore`, `Regiment`, `SpatialGrid`, `Events`, `Orders`). Behaviour is still M0 "advance and fight"; orders are queued, stored in `Regiment.Order`, logged `[Orders]`, not executed.
- Parallel phase reads a tick-start alive snapshot instead of `Hp` (M0 had a data race that broke C3).
- `Battle.tscn` is the main scene; `BattleScene` loads `--scenario=<id>` (default `m0_clash`), fixed tick + interpolation, `--quit-after`, `--shots`, R/Space/Esc. Restarts 6 s after a winner.
- Data: `data/units/gb_spearmen.json`, `data/scenarios/m0_clash.json` (20 × 100, M0 layout, seed 1).

## Public API (what other cards can use)
- `Battle(ScenarioDef, units, ITerrain = null)`, `Issue(Order)`, `Step()`, `ApplyDefs(defs)`, `Rand(soldier, salt)`, `RandAt(tick, soldier, salt)`, `Events`, `Winner` (-1 / team / TeamCount = both broke), `Log` (sink, game sets GD.Print).
- `Regiment`: all C4b fields + `First, Cols, Rows, Def, TargetRegiment, Slot(k)`. `EventKind`: `SoldierKilled`, `RegimentRouted`.
- `UnitDef` / `ScenarioDef` / `DataLoader` (snake_case JSON). `SoldierRenderer.Register(model, builder)`.
- Don't cache `SoldierStore.Pos`/`PrevPos` references across ticks: they are swapped every tick.
